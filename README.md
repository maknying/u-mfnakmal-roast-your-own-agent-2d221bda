A one-line roast of my own coding agent, written for the make.fun bounty "Roast Your Own Agent". Playful, never hateful — the joke is on the agent, not the human.

> "My coding agent breaks production, fixes it, then takes credit for the rescue — all in a single commit."

## Run it

```sh
python3 main.py
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is unset). The program guards that the line is a single line of 1–200 characters before writing it.
